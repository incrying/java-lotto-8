# java-lotto-precourse

## 기능 구현 사항

- [ ]  입력
  - 구입할 금액을 입력 받는다.
  - 당첨 번호와 보너스 숫자를 입력 받는다.

- [ ]  출력
  - 구입한 금액만큼 로또를 출력한다. 
  - 당첨 통계를 출력한다.

- [ ]  로또
  - 로또 번호를 정수 배열로 저장한다.

- [ ]  난수 생성기
  - 1부터 45사이의 수 6개를 뽑는다.

- [ ]  숫자 추출기
  - 입력으로 부터 숫자를 추출해낸다.

- [ ]  당첨 확인자
  - 당첨 번호와 뽑힌 수를 비교한다.

- [ ]  수익률 통계자
  - 구매 금액 대비 당첨 금액을 토대로 수익률을 산출한다.

- [ ]  예외 처리
  - 금액 이외에 다른 문자가 입력되지 않는지 확인한다.
  - 로또 숫자가 6개가 뽑히는지 확인한다.
  - 로또 숫자에 중복이 없는지 확인한다.
  - 금액이 1000원 단위로 입력되는지 확인한다.
  - 딩첨 번호 안에 보너스 숫자가 없는지 확인한다.
  - 당첨 번호가 1-45 사이 값을 넘지 않는지 확인한다.
